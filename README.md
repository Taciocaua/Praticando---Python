# Praticando Python

Repositório criado para registrar minha evolução durante os estudos da linguagem **Python**.

O projeto reúne exercícios e atividades desenvolvidos ao longo das aulas, permitindo acompanhar minha evolução desde os conceitos básicos até conteúdos mais avançados.

## Objetivo

O objetivo principal é desenvolver minha lógica de programação e aprender a utilizar Python para criar soluções de forma simples e organizada.

Durante o desenvolvimento dos exercícios, são praticados conceitos como:

* Lógica de programação
* Estruturas de controle
* Manipulação de dados
* Funções
* Estruturas de dados
* Resolução de problemas

## Conteúdos praticados

O repositório reúne exercícios relacionados a diversos fundamentos do Python, incluindo:

* Variáveis
* Tipos de dados
* Strings
* Entrada e saída de dados
* Operadores
* Estruturas condicionais
* `if`, `elif` e `else`
* Estruturas de repetição
* `for`

* Listas

* Manipulação de dados

## Como executar

Primeiro, certifique-se de que o Python está instalado.

Verifique através do terminal:

```bash
python --version
```

Clone o repositório:

```bash
git clone https://github.com/Taciocaua/Praticando---Python.git
```

Entre na pasta:

```bash
cd Praticando---Python
```

Execute um dos arquivos Python:

```bash
python nome_do_arquivo.py
```
