# 🐍 Praticando Python

Repositório criado para praticar conceitos fundamentais e intermediários da linguagem Python.

Objetivo:

Este repositório tem como objetivo:
- Consolidar lógica de programação
- Praticar sintaxe do Python
- Resolver exercícios e desafios
- Evoluir para projetos mais complexos

Conteúdos abordados:

- Variáveis e tipos de dados
- Estruturas condicionais (`if`, `else`)
- Laços de repetição (`for`, `while`)
- Funções
- Listas, tuplas e dicionários
- Manipulação de strings
- Exercícios práticos
